Дополнительные окна выхода судна (порт, линия, дата).

Строки при открытии подтягиваются из блоков связки порта и линии выше — каждая уникальная пара порт × линия один раз (без повторов из‑за разных типов контейнера в той же связке). «Копировать» — то же окно судна второй строкой без даты: календарь нужно заполнить снова.

Срок действия тарифа по морским линиям *

Для каждой выбранной морской линии укажите период, в течение которого действует тариф по этой линии (в списках и КП год показывается двумя цифрами, например 26).

Сначала укажите морские линии выше — здесь появится по строке на каждую линию; название подставится автоматически, остаётся только выбрать даты «с» и «по».

По каждой строке моря: линия, тип контейнера (сверху), терминал ДВ и станция — укажите стоимость ЖД, RUB.

Стоимость ЖД, RUB *

Стоимость авто доставки до склада (RUB) по каждой строке моря.

Таможенная очистка *

Отметьте один вариант: в порту назначения или на станции назначения (одновременно оба недоступны).

Продажам

Таблица для продаж (отделённая от полного реестра)

Выставьте в блоке фильтров выше направление, период, порты Китая и остальные галочки так, чтобы основная таблица реестра содержала ровно тот состав строк, по которым вы хотите торговаться. Затем нажмите «Сформировать таблицу для продаж» — сюда подтянутся только эти строки. Профит и откат действуют только на них (число в общем списке и цены совпадают: это те же сохранённые ставки). Кнопка «Печать / PDF» открывает диалог печати только по этой таблице; PDF получается, если в диалоге выбрать «Сохранить как PDF» (или аналог) вместо принтера.

Локально включён POST на kp-opened-server (127.0.0.1:3847/kp-opened — см. папку kp-opened-server, нужен SMTP_URL). На другом домене задайте URL в rates.js (TRACKING_ENDPOINT) и при необходимости TRACKING_WEBHOOK_SECRET.
